# Facility directory sources

`ghana_facilities.csv` is generated by `scripts/build_directory.py`. Don't
edit it by hand: fix the source data or the builder, then rebuild. To correct
a single listing, use the superadmin dashboard. The importer never overwrites
records that an organization manages or that have been verified.

## Sources

| Source | What it gives | Licence |
| --- | --- | --- |
| [OpenStreetMap](https://www.openstreetmap.org) via the [Overpass API](https://overpass-api.de) (queries in `scripts/overpass/`) | Health places: names, positions, and phone, hours and website where mapped. Also every named city, town, village, hamlet and suburb | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), © OpenStreetMap contributors |
| [geoBoundaries](https://www.geoboundaries.org) GHA ADM1 (2021) and ADM2 (2019, 260 districts) | Region and district (metropolitan, municipal and district assembly) for each facility | CC BY 4.0. Source: USAID Ghana HPNO and Ghana Statistical Service |
| Optional: [WHO list of public health facilities in sub-Saharan Africa](https://data.humdata.org/dataset/health-facilities-in-sub-saharan-africa) (`ssa.xlsx`) | Extra public facilities missing from OpenStreetMap | CC BY 4.0 |

Data last fetched: 4 November 2026.

**Attribution.** The ODbL requires credit wherever the data is shown. The site
footer and every imported facility profile credit "OpenStreetMap
contributors". Keep these credits. If you publish this CSV, or a database
derived from it, you must offer it under the ODbL.

## Rebuilding

```bash
mkdir -p /tmp/healthdata && cd /tmp/healthdata
UA="FindCareGhana-import/1.0 (info@findcareghana.com)"
curl -A "$UA" --data-urlencode data@<repo>/scripts/overpass/health.overpass \
  https://overpass-api.de/api/interpreter -o osm_health.json
curl -A "$UA" --data-urlencode data@<repo>/scripts/overpass/places.overpass \
  https://overpass-api.de/api/interpreter -o osm_places.json
curl -L -o adm1.geojson https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/GHA/ADM1/geoBoundaries-GHA-ADM1.geojson
curl -L -o adm2.geojson https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/GHA/ADM2/geoBoundaries-GHA-ADM2.geojson
# Optional: download the WHO .xlsx from HDX in a browser (HDX blocks scripts)
# and save it here as ssa.xlsx.

cd <repo>
python scripts/build_directory.py /tmp/healthdata data/ghana_facilities.csv
```

If the Overpass server is busy (HTTP 502 or 504), wait a few minutes and try
again.

## Loading it

- **Development:** `python -m app.seed --reset` loads the hand-made seed and
  then this file. Pass `--no-directory` to skip the file.
- **Live server:** `docker compose exec app python -m app.directory_import`
  adds new places and refreshes earlier imports, and never deletes anything.
  It's safe to run again after each rebuild.

## How fields are derived

- **category:** `amenity`/`healthcare` tags, checked against the name. A
  "Health Centre" or "CHPS" tagged as a hospital becomes a clinic, and a
  clinic tagged as a nursing home stays a clinic.
- **type:** `operator:type` when present. Otherwise government if the name
  says CHPS, District, Municipal, Regional, Teaching, Polyclinic, Health
  Centre and so on. Otherwise private.
- **classification:** GHS level from the name (Teaching → A, Regional → B,
  District or Municipal → C, Polyclinic → D, Health Centre or Clinic → E,
  CHPS → F). Private facilities are "Private". Pharmacies, hearse services
  and caregivers are "Not classified".
- **region / district:** the boundary polygon the point falls in.
- **city:** the address tag, or else the nearest OpenStreetMap city or town
  within 25 km.
- **town (community):** the address tag, or else the nearest village, hamlet,
  suburb or neighbourhood within 4 km.
- **services:** only what the source states, such as Pharmacy, Dental,
  Laboratory, Eye Care, Outpatient, or Antenatal Care and Immunisation for
  CHPS compounds, plus `healthcare:speciality` tags.
